01 — Summary

I come from IT operations for a national retail chain with 320+ stores: building the network for 50+ store openings, running Active Directory, Entra ID and Microsoft 365, and restoring around 100 endpoints during the July 2024 CrowdStrike outage. I worked closely with the security team and want to be on it.

At home I run a segmented lab on Proxmox and OPNsense with its own SIEM and IDS. I use it to practise the full loop a SOC analyst works in: generate the attack, find it in the logs, write the detection, and explain it.

Studying for CompTIA Security+. Heading toward security operations first, then cloud security on Azure.
